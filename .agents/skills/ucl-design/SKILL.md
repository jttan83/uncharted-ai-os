# Uncharted Lab Design System

## Canonical sources
- Canva Brand Kit: **Uncharted Lab — Brand System**.
- Canva Brand Template: **Uncharted Lab — Master Presentation System v2**.
- Verified client/project evidence supplied for the job.

## Critical Canva rule
Do not depend on Canva AI discovering the Brand Kit or Brand Template by name. For presentations, open the actual Master Presentation System v2 Brand Template, choose **Use this Brand Template**, create a working copy, and run Ask Canva inside that copy. The working copy is the layout reference; the prompt carries the non-negotiable rules. Never edit the canonical master directly.

## Workflow
1. Understand audience, decision, desired outcome, constraints, deliverable, deadline, and evidence.
2. Develop narrative and final copy before Canva. Start with the work/problem, not a framework.
3. Map content to existing master layouts. Select, duplicate, reorder, and adapt; do not invent a new visual language.
4. In every Canva production prompt explicitly say:
   - Use the existing layouts in THIS presentation as the strict visual reference.
   - Anton for short high-impact display text; Inter for body, explanation, data, labels, and sources.
   - UL Black #000000; UL Lime #CDFC54; UL Cream #F7F3DB; UL White #FFFFFF.
   - Lime is punctuation, not wallpaper.
   - Signature lime bracket is the primary graphic device.
   - Maintain generous negative space and strong hierarchy.
   - Standard content slides preserve the existing subtle unchartedlab.co bottom-right footer.
   - Cover/formal closing slides preserve approved logo treatment.
   - No gradients, decorative blobs, 3D effects, generic corporate graphics, random icon styles, unnecessary stock imagery, generic AI/pitch-deck styling, or decorative filler.
5. Evidence discipline:
   - Never invent clients, testimonials, statistics, outcomes, credentials, or research.
   - Distinguish evidence from inference.
   - Use explicit placeholders such as [INSERT VERIFIED EVIDENCE] when proof is missing.
   - Never add a photo just because a layout has space.
   - Never use AI imagery to fabricate client work, participants, research, or outcomes.
6. Voice: clear, curious, practical; thinking partner, not guru; simple English; active voice; concise; no hype or generic AI language.
7. Photography: documentary over staged; specific over generic; show the work, not stock. If an image adds no evidence, context, or meaning, leave space empty.
8. Graphics: structure, not decoration. Icons only when they improve comprehension. Charts use the simplest appropriate form and preserve honest scales, labels, units, timeframe, and sources.
9. ChatGPT owns strategy, narrative, evidence structure, final copy, layout mapping, and Canva-ready production prompt. Canva owns assembly/adaptation of layouts already in the working copy.
10. Before external use run **ucl-brand-check**. Jentz remains final approver.

## Modes
- proposal: challenge → understanding → approach → programme/scope → evidence → relevant experience → next steps → formal close.
- workshop: learning journey → activities → timing → instructions → outputs → evidence → facilitator guidance.
- presentation: narrative flow → one idea per slide → evidence-led headlines → audience comprehension.
- report: readability → evidence → sources → conclusions → distinguish findings, interpretation, recommendations.
- social: one useful idea per asset; adapt format without changing the brand system.

## Canva prompt construction
Never rely on: “Use my Uncharted Lab Brand Kit.”

Instead use: “Use the existing layouts in THIS presentation as the strict visual reference. Preserve the established Uncharted Lab system: Anton for display text, Inter for supporting information, #000000, #CDFC54, #F7F3DB and #FFFFFF only, the existing lime bracket treatment, generous negative space, and the existing unchartedlab.co footer position.”

## Success test
The deliverable should feel unmistakably Uncharted Lab even with the logo removed: strong hierarchy, Anton/Inter contrast, restrained palette, purposeful lime, signature bracket, evidence discipline, practical voice, and generous space.
